# Mydex 风险核查与发送保护

核查日期：2026-10-07（Asia/Shanghai）。本报告区分可验证的软件行为与没有公开依据的微信检测传闻。

## 能确认和不能确认的事

- 微信安全中心 2024-03-26 公告明确禁止外挂，并说明按违规程度处理、多次违规加重处罚。可读来源为[华声新闻全文转载](https://news.voc.com.cn/news/202403/22031227.html)，发布日期 2024-03-28。此次检索访问微信官方协议页面失败，因此不声称已逐条核验最新全文。
- 当前方案注入微信客户端并调用内部发送函数，属于未经官方授权的接入；将消息发慢、在本机运行、使用本人登录，都不能消除这一根本风险。要消除这种接入方式带来的风险，须停止使用该通道并迁移到确实获授权的接口，或人工收发。
- 未找到可验证的官方资料说明：特定动态心跳参数、晃动手机、逐字打字或随机延迟可免封。不能从存在传感器或设备数据采集，推断微信的具体封号模型、权重或检测阈值。
- 腾讯云开发者社区的用户投稿不是微信安全团队的官方说明。搜索中“拟人节奏”“万分之三封号率”等宣传没有被用作设计依据。
- 现有 Python 守护程序的检查是本机进程/面板存活检查，不是向微信服务器发送保活包。本轮没有修改微信网络心跳、传感器数据、设备指纹、输入状态或客户端检测逻辑。

## 已实施的保护

| 项目 | 行为 |
| --- | --- |
| 指定群 | 保留原有两个群的 ID 白名单；本轮不增加群，不发送群通知或测试消息 |
| 触发 | 真实入站 @ 才进入自动问答；普通消息只归档。既有本人显式测试命令仍保留，不响应自己的普通回复 |
| 同一成员 | 同群 30 秒内的连续提问不重复触发模型；消息仍保存 |
| 排队 | 每群最多 8 条等待中的提问；队列满时保留聊天记录，不积压待发送消息 |
| 新鲜度 | 超过 10 分钟的提问/草稿不自动发；时钟明显回退或未来时间异常时停止发送 |
| 重启 | 所有群、所有新发现分片都先建立历史基线；不追赶群加入时间以来的旧 @ |
| 发送间隔 | 全部群共用至少 8 秒间隔，同群至少 20 秒。按防刷屏策略排队，不声称模拟真人 |
| 滚动限额 | 每群 20 条/小时、60 条/24 小时；全局 30 条/小时、100 条/24 小时。超限保留草稿，不安排自动补发 |
| 去重 | 同群同内容 10 分钟内拦截；同群同一提问的发送尝试持久化去重，不因重启或手动恢复而补发 |
| 持久化 | 本机 SQLite 在调用微信前先登记发送尝试，跨进程事务互斥；去重表只保存摘要与元数据，不额外保存消息正文 |
| 结果不明 | 单次发送异常、拒收或无法验证服务器记录后，打开持久化暂停开关，阻止后续自动发送；先核对微信和群记录，再在本机手动恢复 |
| 人工暂停 | 冷却期间可以立即暂停；已经交给微信的发送无法承诺撤回 |
| 会话校验 | 核对 PID、进程创建时间和已验证会话标记；不接受旧 PID 复用。未验证会话时，服务启动不读取旧群历史 |
| 注入重试 | 同一客户端进程会话只自动尝试一次安装；失败后本地检查按 10/20/40/60 秒退避，不反复注入 |
| 既有保护 | 保留原生版本/文件哈希验证、群内独立上下文、媒体凭证剥离、只读数据库和本机密钥保护 |

以上数值是项目选定的保守使用限制，不是微信公布的免封阈值。所有发送尝试（包括未确定结果的尝试）都消耗预算；研究脚本的人工直接调用不属于应用自动发送入口，日常使用应通过启动脚本和服务。

## 使用和剩余限制

- 换号必须重新核对当前账号、目标群、数据库及发送会话。此版本还不支持自动识别并无缝迁移所有微信账号；同一进程内账号切换也不能仅凭 PID 检出。换号前应暂停助手，重新验证后再恢复。
- 原生状态可读不等于账号没有风控。当前没有可靠的封号/验证码弹窗识别接口，不宣称能自动识别所有平台警告；出现限制或验证提示时应立即在面板关闭自动发送，人工处理。
- 初始化/重启期间的新消息可能只进入历史基线，不补发。这是为避免恢复后刷屏所作的取舍。
- 限额拦截、队列满、成员冷却或回复过期时不会在群里额外发送错误提示，以免制造更多消息；可在本地状态和草稿中检查。
- 群内应让成员知晓这是 AI 助手，以及指定群的相关文字会经在线模型处理。跨群隐私与未实际读取的附件正文仍不能进入回答。
- 本轮验证采用自动测试和本机服务状态检查，不通过向真实群批量发消息来测试限额，不声称已验证实际封号概率。

主要实现：`send_guard.py`、`native_sender_bridge.py`、`database_inbox.py`、`assistant_supervisor.py`、`server.py`。不需要新安装软件；Windows 自启配置未改动。
