# Working agreement

Install software under D:\Software. Never commit .local, model secrets, WeChat login or DB keys, SSH keys, chat histories or raw captures. Keep a single active sender during migration. Read deployment/HANDOFF.txt before changing startup, native hooks or account enrollment. Never remove version/hash checks to make an unsupported client run. Mark quote sending and unverified deployment steps truthfully. After changes, update the handoff and use separate commits so the other computer can pull safely.
